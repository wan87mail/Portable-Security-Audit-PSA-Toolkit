# Baselines

Organisation-supplied security baselines are imported here for Module F
(Phase 7). Each baseline maps a check or setting ID to the expected value.
Comparisons are reported as *deviations from the supplied baseline*, never as
formal compliance or certification.

CIS Benchmark content is licensed by CIS and is not shipped with the toolkit.
Organisations with a CIS licence may transcribe the settings they adopt into
this format.
